# Future Causal Field

Research implementation of the Future OS mechanism layer.

WORLD -> MECHANISM STATE -> CAUSAL VELOCITY/ACCELERATION -> LAG COMPRESSION -> GENERATIVE REGIME -> FUTURE ATTRACTORS -> PRESSURE -> FALSIFICATION/SURVIVAL -> FUTURE COLLAPSE -> NEXT BEST OBSERVATION.

Semantics:
- Observational edge strength is **association** unless a causal identification strategy exists.
- **Pressure is not probability.**
- **Survival is a stress score, not probability.**
- Next Best Observation is active sensing coupled to competing futures and falsification.
- Production inputs must obey point-in-time availability and vintage rules.
- Calibration must be frozen inside training folds.
- Novelty is a research hypothesis, not a claim that no prior literature contains related ideas.

Production gate:
1. strict vintage audit passes;
2. prediction journal proves prediction-before-reveal;
3. expanding walk-forward backtest beats preregistered baselines;
4. ablations show the mechanism layer adds out-of-sample value;
5. falsifier and decision-window metrics are reported.
